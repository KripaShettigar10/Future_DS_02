🌟 Project Overview

Customer churn is a major challenge for businesses, especially in the telecommunications industry. Understanding why customers leave helps organizations improve their services, strengthen customer relationships, and build effective retention strategies.

This project analyzes the Telco Customer Churn Dataset using Python and Microsoft Power BI to identify customer churn patterns, explore important factors associated with customer cancellations, and present the findings through data visualizations and an interactive dashboard.

🎯 Project Objectives

- Analyze customer churn and retention patterns.
- Explore the relationship between churn and contract type, internet service, and payment method.
- Compare average monthly charges and customer tenure between churned and retained customers.
- Identify key business insights from customer data.
- Develop a Power BI dashboard for clear and effective data presentation.
- Recommend strategies to support customer retention.

📂 Dataset Details
- Dataset Name : Telco Customer Churn Dataset
- Source : Kaggle
- Domain : Telecommunications / Customer Analytics
- Total Records : 7,043 customers
- Target Variable : "Churn"
- Purpose : Analyze customer churn patterns and factors associated with customer cancellations

🛠️ Tools & Technologies

- Python — Data analysis and preprocessing
- Pandas — Data manipulation and cleaning
- Matplotlib — Data visualization
- Seaborn — Exploratory data visualization

- Microsoft Power BI — Dashboard development
- GitHub — Project documentation and version control

🔍 Project Workflow

1. Data Collection: Loaded the Telco Customer Churn dataset.
2. Data Cleaning: Converted "TotalCharges" to a numeric format and handled missing values.
3. Exploratory Data Analysis: Examined churn distribution and customer characteristics.
4. Visualization: Created graphs to identify patterns across customer groups.
5. Dashboard Development: Built a Power BI report with KPI cards and five analytical charts.
6. Insights & Recommendations: Summarized findings and proposed customer retention strategies.

📈 Key Findings

- Overall Churn Rate: 26.54%
- Customer Retention Rate: 73.46%
- Total Customers: 7,043
- Customers Who Churned: 1,869
- Highest-Risk Contract Group: Month-to-month customers, with a churn rate of approximately 42.71%.
- Payment Method Pattern: Electronic check users had a churn rate of approximately 45.29%.
- Internet Service Pattern: Fiber-optic customers had a churn rate of approximately 41.89%.
- Customer Tenure: Churned customers had a shorter average tenure than retained customers.
- Monthly Charges: Churned customers had higher average monthly charges than retained customers.

Note: These findings show associations in the dataset and do not independently establish the causes of churn.

💡 Business Recommendations

- Improve onboarding and engagement for new customers.
- Offer suitable incentives for customers considering long-term contracts.
- Review pricing plans and communicate service value clearly.
- Investigate service quality and customer experience among fiber-optic users.
- Encourage convenient payment options while examining issues faced by electronic check users.
- Strengthen technical support and complaint resolution.
- Monitor churn and retention metrics regularly using the Power BI dashboard.
